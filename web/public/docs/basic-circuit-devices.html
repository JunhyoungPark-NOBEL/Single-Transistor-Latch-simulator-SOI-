MOSFET · Diode · BJT · 300 K

교육·기본 동작용 300 K compact model입니다. 기생 커패시턴스, MOS 바디 다이오드, 접합 항복, 자기 발열, 공정별 효과는 없습니다. 소자 내부에 동적 전하 상태가 없으므로 회로의 동특성은 외부 커패시터로 넣어 주세요. BSIM이나 Gummel–Poon 같은 제조사 모델이 아닙니다.

모델 식

MOSFET — 매끄러운 대칭 square-law

NMOS는 σ = +1, PMOS는 σ = −1이며 각 단자 전압을 v′ = σv로 바꿉니다. SS를 V/dec 단위로 두고 s = SS / ln 10입니다.

f(x) = 2s · ln[1 + exp(x / 2s)],   K = k·W/L
I_D  = (σK/2) · { f(v′g − v′s − |Vth|)² − f(v′g − v′d − |Vth|)² } · (1 + λ|v′d − v′s|)

강반전에서는 square-law에, 약반전에서는 지정한 subthreshold swing에 수렴합니다. 게이트 전류는 0, 소스 전류는 −ID입니다.

다이오드 
I = Is · [exp((Va − Vk) / (n·VT)) − 1],   VT = 0.025852 V
BJT — 상반 Ebers–Moll (transport Is)

NPN은 σ = +1, PNP는 σ = −1입니다.

F = exp[σ(Vb − Ve)/VT] − 1,   R = exp[σ(Vb − Vc)/VT] − 1
αF = βF/(βF + 1),   αR = βR/(βR + 1)
I_C = σ·Is·(F − R/αR),   I_E = σ·Is·(R − F/αF),   I_B = −I_C − I_E

다이오드·BJT 지수 항은 인자 xmax = min(max(40, ln(1 A / Is)), 700) 이상에서 C¹ 선형 연장을 사용해 Newton 시도값을 유한하게 유지합니다. Is ≥ 4.2×10⁻¹⁸ A이면 xmax = 40이고, 이보다 작은 Is는 접합 전류가 1 A에 이르는 지점에서 연장이 시작되므로 일반적인 동작 전류에서는 지수 특성을 유지합니다. 고주입 모델이 아니라 수치 안전장치입니다. Newton 반복에서는 임계 전압을 넘는 순방향 접합 전압 증가만 SPICE pnjlim처럼 로그로 줄이고, 역방향·감소 방향 스텝은 제한하지 않습니다.

English

MOSFET, diode and BJT elements join the same nonlinear MNA operating-point and transient solve as STL, R, C and sources; a circuit does not need an STL. They are educational 300 K compact models without parasitic capacitance, MOS body diodes, junction breakdown, self-heating or process-specific effects, and they have no internal charge state — add external capacitors for dynamics. MOS uses a smooth symmetric square law with the given subthreshold swing; the diode uses the Shockley equation; the BJT uses reciprocal Ebers–Moll with transport saturation current. Terminal probes are currents into each terminal. The accepted input ranges only reject malformed input and do not establish physical validity.
