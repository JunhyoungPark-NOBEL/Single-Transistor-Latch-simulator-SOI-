기준 소자의 차원 관계를 확장한 모델입니다.

Deterministic · VSCM / CSVM

새로운 치수의 측정 적합 모델은 아닙니다. Tsi는 접합 표면 SRH 우세 가정, Tbox는 VBG를 통한 정전용량 결합을 사용합니다. n+ 소스·드레인으로의 정공 주입은 접합 면적에만 비례합니다.

소스·드레인 정공 주입

바디 정공이 n+ 소스(이미터)로 들어가는 전류는 n+ 쪽 도핑과 정공 확산 길이로 정해지고, 이 둘은 L·Nbody로 바뀌지 않습니다. 그래서 포화 전류는 보정 소자의 값을 접합 면적 비율로만 바꿉니다.

Isp = q·A·Dn·ni² / (NA,ref·Lref,0·β),   A = W × Tsi

β, NA,ref, Lref,0은 보정 소자의 값입니다. L·Nbody가 바꾸는 것은 바디 쪽 수송(중성 베이스 길이, 재결합, 전계표)입니다. 과도 상황의 순방향 드레인 다이오드도 같은 식을 씁니다. 기준 치수의 결과는 달라지지 않습니다.

Tsi와 표면 재결합

기존 접합 손실을 표면 우세 항으로 해석합니다. 새 손실 항을 더하지 않습니다.

τj,eff = τj,ref × Tsi / 50 nm
Ij ∝ W × Tsi × ws / τj,eff ∝ W × ws

표면/벌크 기여율은 측정으로 분리하지 않았습니다. tau_bulk는 유지합니다. 매우 얇은 소자의 정량 예측에는 추가 보정이 필요합니다. 임의의 knee·양자 항·전압 이동식은 없습니다.

Tbox와 VBG
Cb = (1/Csi + 1/Cbox)⁻¹
ηBG = Cb/Cf = EOT / (Tbox + Tsi/3)
채널 overdrive += ηBG × VBG

VBG는 소스 기준 고정 바이어스입니다. 전면 GIDL에는 실제 VG를 사용합니다. BJT 장벽이나 β의 추가 이동은 없습니다.

Qcap = Cf(ψ−VG) + (Cb−Cb0)ψ − Cb·VBG

Cb0는 현재 L·W에 대한 기준 Si/BOX 정전용량이며, 원래 보정을 유지하는 보상항입니다. 음의 물리 정전용량이나 완전한 Poisson 해석을 뜻하지 않습니다. VBG=0에서는 Tbox에 따른 DC 문턱 이동을 강제로 만들지 않습니다.

이 선형 결합은 백 계면이 공핍된 범위에서만 성립하므로 EOT/(Tbox + Tsi/3) × |VBG| ≤ 2 V까지만 계산합니다. VBG는 전면 채널 전류에만 작용하므로, 채널이 꺼진 VG ≲ −1.5 V에서는 VLU·VLD가 거의 변하지 않습니다. 백게이트에 의한 바디 정공 저장 효과는 포함하지 않습니다.

범위와 사용 방법
  • 래치가 유지되는 검사 범위에서 L 감소 → VLU·VLD 감소, Tsi 감소 → 두 전압 증가를 확인했습니다.
  • W의 전압 불변은 dark 조건의 결과입니다. 지정한 Iph·Iin·Cdrain은 자동으로 폭에 비례하지 않습니다.
  • 모델이 성립하지 않는 조합은 "래치 없음" 같은 결과로 보고하지 않고 거부합니다: L ≤ 2·wd0(Nbody) + 1 nm(기준 Nbody에서 153.6 nm, 3×10¹⁶ cm⁻³에서 412.2 nm), EOT/(Tbox + Tsi/3) × |VBG| > 2 V, 전계표가 역바이어스 3 V에 닿지 않는 Nbody. 화면에는 넘은 한계를 알려 줍니다. 입력 범위 전체가 검증된 것은 아닙니다.
  • 치수·VBG 변경은 결정론 모드와 실시간 계산 서버를 사용합니다. 확률 모델은 기준 조건에서만 보정되어 있습니다.
  • LTspice·Verilog-A에는 현재 고정 치수와 바이어스가 기록됩니다. 조건을 바꾸면 다시 계산하고 내보냅니다.

English · scope

The six dimensions are anchored to the original calibration. Tbox=140 nm is an explicit nominal assumption. Thickness scaling assumes surface-dominated junction SRH; the surface fraction was not independently extracted. Back-gate coupling is a first-order Si/BOX capacitive channel bias with reference-anchored incremental charge, valid while EOT/(Tbox + Tsi/3) × |VBG| ≤ 2 V; it acts on the front-channel current only, so with the channel off (VG below about −1.5 V) VLU and VLD hardly change. Hole injection into the n+ source/drain scales with the junction area W × Tsi only (fixed emitter). No artificial fold-voltage offsets, quantum knee, or BJT barrier shifts are introduced.

Changed dimensions or VBG require the live deterministic solver. Unsupported combinations are rejected, never reported as a physical "no latch": L ≤ 2·wd0(Nbody) + 1 nm, back-gate coupling above 2 V, or an Nbody whose avalanche-field table ends below 3 V (Nbody input range 3×10¹⁶–1.1×10¹⁸ cm⁻³). Saved devices and circuit snapshots preserve all dimensions and VBG. Exports are quasi-static models at the chosen fixed geometry and bias, not geometry-parameterized commercial device models.
