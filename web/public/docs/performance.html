STL SIMULATOR · PERFORMANCE

성능 측정과 예상 시간

모델별 기준 시간과 현재 계산 환경의 기록을 함께 사용합니다.

사용 방법

  1. 성능 탭에서 모델·해석 종류별 기준 시간을 확인합니다.
  2. 이 환경 측정으로 현재 연결된 Python 계산 환경을 측정합니다.
  3. 소자·회로 실행 버튼 근처에서 현재 설정의 예상 시간을 확인합니다.

로컬 앱은 사용자 PC, 원격 연결은 연구실 서버의 속도를 사용합니다. 환경 측정 전에는 기준 환경 추정으로 표시합니다.

표의 숫자는 어떻게 측정하나요?

같은 외부 입력과 수치 허용오차로 모델을 직접 실행합니다. 반복 계산의 중앙값을 표시하고 최소–최대, 반복 횟수와 실제 요청을 함께 기록합니다. 최종 결과 캐시에서 응답한 시간은 모델 계산 속도에 포함하지 않습니다.

첫 호출은 기존 컴파일 캐시 읽기나 조건별 계산표 생성이 섞일 수 있어 따로 기록합니다. 이 숫자는 새 설치에서 모든 수치 커널을 처음 컴파일한 시간과 다릅니다.

Simple의 확률적 해석처럼 지원하지 않는 조합은 미지원으로 표시합니다. MOSFET·diode·BJT만 있는 회로는 STL 모델에 무관한 공통 결과입니다.

내 PC의 예상 시간은 어떻게 구하나요?

모델과 해석 종류가 같은 기준 결과를 찾아 격자·게이트 점수, 회로 크기, 해석 길이·시간 간격, 구동 조건과 반복 횟수에 맞춰 환산합니다. 환경 측정은 브라우저의 연산이 아닌 실제 Python 모델 계산입니다.

측정한 모델·해석 종류에 보정을 적용하고, 성공한 실제 실행으로 예측을 갱신합니다. 측정 자료가 없는 종류는 기준 환경 추정으로 구분합니다. 다른 서버나 새 엔진의 기록을 섞지 않습니다.

실패·취소·중도 종료, 캐시 응답, 동일 계산을 함께 요청한 사용자의 중복 시간은 정상 실행 시간으로 학습하지 않습니다.

첫 환경 측정은 준비 과정 때문에 더 오래 걸릴 수 있습니다. 확률적 해석도 새로운 조건의 내부 계산표를 만들 때 추가 시간이 생길 수 있습니다.

예상 범위와 비교의 한계

표시 범위는 실행 부담을 판단하기 위한 추정이며 통계적 신뢰구간이 아닙니다. 적응 시간 간격, 수렴 난이도, 새로운 바이어스·기하·회로, 동시 사용량에 따라 실제 시간이 달라질 수 있습니다.

실행 버튼이 여러 계산을 요청하면 병렬 실행과 순차 의존성을 함께 고려합니다. 아직 수치 풀이를 하지 않았으므로 실제 스텝 수나 모든 수렴 실패를 미리 확정할 수는 없습니다.

속도 비교는 물리 정확도 비교가 아닙니다. Simple과 Detailed는 근사와 기본 파라미터가 달라 같은 입력에서도 다른 파형을 만들 수 있습니다.
