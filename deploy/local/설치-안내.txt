STL Simulator 설치 안내  (버전 {VERSION}, {DATE})
=====================================================

이 폴더의 설치 파일을 실행하면 STL Simulator가 내 컴퓨터의 Docker 안에 설치되고,
브라우저에서 http://127.0.0.1:8000 으로 쓸 수 있습니다. 시뮬레이터 프로그램은 암호화되어 있어서
연구실에서 받은 비밀번호가 있어야 설치됩니다.

■ 준비물
  - 메모리(RAM) 8 GB 이상 권장, 디스크 여유 공간 5 GB 이상
  - 처음 설치할 때 인터넷 연결 (필요한 부품을 내려받아 조립합니다: 5–15분)
  - Docker Desktop (무료). 없으면 설치 파일이 설치를 도와줍니다.
  - Windows: Windows 10/11 64비트 + WSL2 (Docker Desktop 설치 과정에서 함께 안내됩니다)
  - macOS: Intel, Apple Silicon(M1–M4) 모두 가능

■ 설치 순서
  1) Docker Desktop 설치
     https://www.docker.com/products/docker-desktop/ 에서 받아 설치하고, 한 번 실행해서 약관에 동의해 둡니다.
     (Windows는 설치 후 재부팅이 필요할 수 있습니다.)

  2) 설치 파일 실행  — 먼저 ZIP 압축을 전부 풉니다 (Windows: ZIP 파일 오른쪽 클릭 → "압축 풀기" / "모두 압축 풀기").
     - Windows: install-windows.bat 더블클릭
         "Windows의 PC 보호" 창이 나오면 "추가 정보" → "실행".
     - macOS:   install-mac.command 더블클릭
         "확인되지 않은 개발자" 경고가 나오면: 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기".
         또는 "터미널"을 열고  bash  를 입력한 뒤 한 칸 띄우고, install-mac.command 파일을 터미널 창에
         끌어다 놓고 Enter.
         "터미널이 다운로드 폴더에 접근하려고 합니다" 창이 나오면 "허용".
     - Linux:   키트 폴더에서 터미널을 열고  bash install-linux.sh   (sudo 없이)

  3) 비밀번호 입력  — 입력하는 글자는 화면에 보이지 않습니다. 입력 후 Enter. (3번까지 다시 입력할 수 있습니다)
     키보드가 영문(한/영) 상태인지 확인하세요. 받은 비밀번호를 복사해 붙여 넣어도 됩니다.

  4) 브라우저에서 사용  — 설치가 끝나면 브라우저가 자동으로 열립니다.
     주소: http://127.0.0.1:8000  (8000번이 사용 중이면 8001–8010 중 빈 번호. 설치 끝에 주소가 표시됩니다)
     다음부터는 바탕화면/시작 메뉴(Windows), 설치 폴더의 "STL Simulator 열기"(macOS),
     프로그램 메뉴(Linux)의 STL Simulator로 엽니다.

■ 설치 위치와 사용법
  - Windows: %LOCALAPPDATA%\STL-Simulator      - macOS/Linux: 홈 폴더의 STL-Simulator
  - 설치 폴더의 README-사용법.txt 에 시작 / 중지 / 되돌리기 / 제거 방법이 있습니다.

■ 업데이트
  새 설치 키트를 받으면 같은 방법으로 설치 파일을 다시 실행하면 됩니다. 설정과 포트는 그대로이고,
  바로 전 버전은 되돌리기용으로 남겨 둡니다.

■ 주의
  - 이 키트와 비밀번호를 연구실 밖으로 공유하지 마세요 (발표 전 연구 내용입니다).
    키트와 비밀번호를 같은 메시지로 보내지 마세요.
  - 문제가 생기면 화면에 나온 오류 문구와 설치 폴더의 logs 폴더를 담당자에게 보내 주세요.
    (비밀번호는 어디에도 기록되지 않습니다)

English: extract the ZIP, run install-windows.bat (Windows), install-mac.command (macOS) or
"bash install-linux.sh" (Linux), enter the password, and the simulator opens at http://127.0.0.1:8000.
Needs Docker Desktop, 8 GB RAM recommended, 5 GB free disk, and internet for the first build (5-15 min).
Run the installer of a newer kit to update; the install folder's README-사용법.txt explains the rest.
