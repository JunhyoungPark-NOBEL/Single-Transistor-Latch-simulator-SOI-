# Geometry 모델 — 차원 감사와 적용 범위

2026-09-25 · `fdsoi-scaling-v1`

기존 보정 소자를 기준으로 차원 관계를 확장했습니다. 새로운 치수의 측정·TCAD 데이터에
맞춘 모델은 아닙니다. 원본 `engine/`는 보존하고 `server/geometry_model.py`와 회로 연결부에
확장을 구현했습니다. 기준 치수·VBG=0은 기존 수치 커널을 그대로 사용합니다.

## 기준점과 입력

Geometry는 왼쪽 파라미터의 첫 항목입니다. Tox는 산화막의 물리 두께가 아닌 **EOT**로 입력합니다.
VBG는 VG 바로 아래에서 조절하며 소스 기준의 고정 백게이트 전압입니다.

| 입력 | 기준 | 입력 범위 | 출처 |
|---|---:|---:|---|
| L | 500 nm | 100–2,000 nm | 원본 구조 |
| W | 200 nm | 20–10,000 nm | 원본 구조 |
| Tsi | 50 nm | 5–200 nm | 원본 구조 |
| Tox / EOT | 14.1 nm | 1–100 nm | 원본 보정 |
| Tbox | 140 nm | 10–1,000 nm | **원본에 없어 설정한 명시적 기준 가정** |
| Nbody | 2.295773162796593×10¹⁷ cm⁻³ | 3×10¹⁶–1.1×10¹⁸ cm⁻³ | 원본 보정 JSON의 실제 값 |
| VBG | 0 V | −10–10 V (아래 결합 한계 안에서) | 기준 바이어스 |

범위는 입력 허용 범위이며, 전체 조합의 모델 유효성을 보장하지 않습니다. 이 축약 모델이
성립하지 않는 조합은 물리 결과(예: "래치 없음")로 보고하지 않고 계산 전에 거부합니다.

| 조건 | 거부 기준 | 확인 위치 |
|---|---|---|
| 횡방향 중성 베이스 | `L ≤ 2 wd0 + 1 nm` (기준 Nbody에서 L ≤ 153.6 nm, Nbody = 3×10¹⁶ cm⁻³에서 L ≤ 412.2 nm) | 요청 검사(HTTP 422) |
| 백게이트 선형 결합 | `EOT/(Tbox + Tsi/3) × \|VBG\| > 2 V` | 요청 검사(HTTP 422) |
| avalanche 전계표 | 도핑별 유한(subcritical) 전계표가 역바이어스 3 V까지 닿지 않음(Nbody ≳ 1.14×10¹⁸ cm⁻³) | 계산 작업 |

여기서 `wd0 = sqrt(2 εSi vbi / (q Nbody))`, `vbi = VT ln(Nsource Nbody / ni²)`입니다. 거부 메시지는
`geometry-domain-unavailable:`로 시작하고, 회로에서는 해당 셀 이름(예: `X1:`)이 앞에 붙습니다. 화면에는 넘은
한계(예: "L을 153.6 nm보다 길게")를 한국어·영어로 보여 줍니다. Nbody 입력 범위의 위쪽 끝 1.1×10¹⁸ cm⁻³는
전계표 조건을 만족하는 값입니다. 횡방향 중성 베이스와 수직 방향 fully-depleted 근사는 별개이며, 이 확장은 FD
상태를 자동 판정하는 2D Poisson 해석기가 아닙니다.

## 기존 식에서 빠져 있던 차원 관계

| 항목 | 연결한 관계 | 유지한 보정값·한계 |
|---|---|---|
| L | 접합 공핍폭을 뺀 수송 길이(중성 베이스), 확산·재결합, 채널 W/L | 임의의 VLU·VLD 이동식 없음; 소스·드레인 주입 포화 전류는 불변 |
| W | 접합 면적·GIDL 생성 부피·채널·전하 ∝ W, 접촉·access 저항 ∝ 1/W | 어두운 조건에서 래치 전압 불변; 가장자리·좁은 폭 효과는 미보정 |
| Tsi | 접합 면적 W·Tsi, 저장 부피, 접합 표면 SRH 수명, Si/BOX 직렬 정전용량 | bulk 유효 수명은 유지; 얇은 바디의 양자 보정·임의 knee 없음 |
| EOT | Cf=εox LW/EOT, 채널 계수 ∝1/EOT, GIDL 유효 전계 길이 ∝EOT | 기존 GIDL 추출 길이를 기준으로 비율 적용 |
| Tbox | Si/BOX 직렬 정전용량, 채널 VBG 결합, 증분 저장 전하 | 임의의 BJT β·장벽 이동 없음 |
| Nbody | 중성 조건·내장전위·공핍폭·SRH·avalanche/BTBT 전계표 | 채널 Vth·이동도·수명의 도핑 의존성은 별도 추출하지 않음; 소스·드레인 주입 포화 전류는 불변 |

`t_access`, `L_access`, `NA_access`는 독립적으로 보정한 access slab입니다. L 또는 Tsi와
자동으로 동일시하지 않습니다. W에 대한 저항 스케일은 적용합니다.

## 소스·드레인 정공 주입: 접합 면적에만 비례

바디의 정공이 n+ 소스(BJT의 이미터)로 확산해 들어가는 손실 전류는 n+ 쪽의 도핑과 정공 확산 길이로 정해집니다.
이 둘은 L이나 Nbody를 바꿔도 달라지지 않으므로, 포화 전류는 보정 소자의 값을 접합 면적 비율로만 바꿉니다.

```text
Isp = q · A · Dn · ni² / (NA,ref · Lref,0 · β)        A = W · Tsi
Lref,0 = L0 − 2 wd0(NA,ref),  L0 = 500 nm            (보정 소자의 영바이어스 중성 베이스 길이)
Idiff = Isp · exp(−φE / VT) · expm1(u / VT)
```

`β`는 보정값 그대로이며, `NA,ref`와 `Lref,0`도 보정 소자의 값입니다. L이나 Nbody에 따라 바뀌는 것은 바디 쪽
수송(중성 베이스 길이, 재결합, 전계표)뿐입니다. 드레인 접합이 순방향으로 걸리는 과도 상황의 드레인 다이오드도
같은 식을 씁니다. 결과 메타데이터에는 `emitter_injection_scaling = "area only (fixed n+ source/drain)"`로
기록됩니다.

GPT 초안은 이 전류를 `Nbody·(현재 L의 베이스 길이)`로도 나눠 β를 고정한 채 바디 쪽 값에 묶었습니다. 이 경우 L을
줄이거나 Nbody를 바꿀 때 n+ 소스의 성질까지 바뀐 것처럼 계산됩니다. 소유자 결정(D8, 2026-09-25)에 따라 면적만
반영하는 방식으로 바꿨습니다. 기준 치수의 결과는 두 방식에서 같습니다.

| 변경 (VG=−2 V) | GPT 초안 VLU/VLD (V) | 현재 VLU/VLD (V) |
|---|---:|---:|
| L=400 nm | 3.6095 / 2.5556 | 3.5821 / 2.2423 |
| L=300 nm | 3.4490 / 2.4735 | 3.4066 / 1.8148 |
| L=200 nm | 2.6504 / 2.1490 | 2.6425 / 1.2454 |
| L=1,000 nm | 3.9345 / 2.6901 | 4.1646 / 3.8643 |
| Nbody 1×10¹⁷ | 4.0807 / 3.9442 | 3.8488 / 2.8717 |
| Nbody 5×10¹⁷ | 3.5265 / 1.7031 | 3.6025 / 2.6349 |
| Nbody 1×10¹⁸ | 3.3995 / 1.1843 | 래치 없음 |

사용자가 지정하는 광전류 `Iph`는 **절대 전류**입니다. W를 바꿔도 자동으로 늘리지 않습니다.
반면 기준 폭의 전류로 추출된 채널 seed와 local saturation 전류에는 폭 비율을 적용합니다.
따라서 고정 Iph 또는 고정 외부 Iin·Cdrain에서 W를 바꿀 때까지 모든 전압·주파수가
불변이라는 뜻은 아닙니다.

## Tsi: 접합 표면 SRH 우세 가정

얇은 층에서 표면 재결합의 유효 손실률은 표면/부피 비에 의존합니다. 이번 구현은 원본의
유효 접합 SRH 항에 표면 기여가 우세하다는 가정을 적용합니다.

```text
τj,eff = τj,ref · Tsi / Tsi,ref
Ij = q · W · Tsi · ws · ni / (2 τj,eff) · expm1(u / 2VT)
   = q · W · ws · ni · (Tsi,ref / τj,ref) / 2 · expm1(u / 2VT)
```

즉 이 손실 항은 접합 부근의 표면적 W·ws에 비례합니다. 새로운 재결합 전류를 더하지 않고
기존 항의 두께 관계를 바꿉니다. 기준 보정에서 유도되는 `Stop+Sbottom ≈ 933 cm/s`는
**이 가정의 등가값**이며 측정으로 추출한 표면 재결합 속도가 아닙니다.

원본 τj는 유효 접합 수명으로, 표면/벌크 성분이 독립적으로 식별되지 않았습니다.
여기서 표면 기여를 100%로 보는 선택과 기존 `tau_bulk`의 물리적 분해에는 불확실성이
남아 있습니다. 중성 바디 전체의 계면 재결합을 새로 푼 것도 아닙니다. 따라서 Tsi가 매우
얇을 때 변화의 **정량 크기**까지 검증했다고 해석하면 안 됩니다. 여러 Tsi에서의 측정과
표면 처리 조건이 있어야 이를 재추출할 수 있습니다.

## Tbox: 실제 백게이트 결합만 추가

Si와 BOX의 정전용량을 직렬 연결한 1차 근사입니다. εSi/εox=3을 사용합니다.

```text
Cf = εox · L · W / EOT
Csi = εSi · L · W / Tsi
Cbox = εox · L · W / Tbox
Cb = (1/Csi + 1/Cbox)⁻¹
ηBG = Cb/Cf = EOT / (Tbox + Tsi/3)
channel overdrive += ηBG · VBG
```

이는 기준 VBG=0 주위의 채널 바이어스 근사입니다. 전면 GIDL에는 실제 VG를 그대로
사용합니다. BJT β·emitter barrier 또는 내부 quasi-Fermi splitting을 임의로 이동시키지
않습니다. 독립적인 백채널 전류나 2D 전위 분포를 푸는 모델은 아닙니다.

이 선형 결합은 백 계면이 공핍된 범위에서만 성립하므로 `EOT/(Tbox + Tsi/3) × |VBG| ≤ 2 V`까지만 계산합니다.
기준 적층(EOT 14.1 nm, Tbox 140 nm, Tsi 50 nm)에서는 결합비가 0.09라 입력 범위 ±10 V 전체가 들어가지만,
EOT 100 nm·Tbox 10 nm·Tsi 5 nm처럼 결합비가 8.6이면 |VBG| > 0.23 V에서 거부합니다. 또한 이 모델에서
VBG는 전면 채널 전류에만 작용합니다. 채널이 꺼진 VG ≲ −1.5 V에서는 VLU·VLD가 거의 변하지 않으며(기준 소자,
VG = −2 V, VBG = 0.5 V: 3.703689/2.597867 V로 VBG = 0과 같음), 백게이트에 의한 바디 정공 저장 효과는 포함하지
않습니다(메타데이터 `backgate_scope`).

전하에는 기준 보정을 유지하는 증분식을 사용합니다.

```text
Qcap = Cf(ψ − VG) + (Cb − Cb0)ψ − Cb·VBG
Cb0 = εox · L · W / (Tbox,ref + Tsi,ref/3)
Qtotal = Qcap + 기존 excess-carrier 전하 + 기존 ionized-dopant 전하
```

`Cb0`는 현재 L·W 면적에 대한 **기준 보정 보상항**입니다. 음의 물리 정전용량을
추가한다는 의미가 아니며, 이 식을 완전한 Poisson 해로 주장하지 않습니다. 기준 치수와
VBG=0에서 기존 전하식과 일치합니다. `∂Qcap/∂VBG=−Cb`,
`∂Qcap/∂ψ=Cf+Cb−Cb0`이고 후자는 허용 치수 범위의 경계 조합에서 양수임을 확인했습니다.

VBG=0에서는 추가한 채널 바이어스 항이 0입니다. Tbox를 바꾸면 저장 전하는 달라지지만
그 이유만으로 DC VLU·VLD를 강제로 이동시키지 않습니다. 실제 영바이어스 Tbox 의존성을
추출하려면 백게이트 일함수·flat-band·계면전하 등의 정보가 더 필요합니다.

벤치마크가 아닙니다. 재생성 스크립트와 수치는 `web/e2e/fixtures/geometry/`에 있습니다.

8 ms까지 완료했습니다(6,130 스텝, 저장 샘플 3,093개). 래치업·래치다운이 각각 4회 발생했고

fold(3.5821/2.2423 V)와 구분합니다. 실제 요청과 solver 요약은
`web/e2e/fixtures/geometry/csvm-check.json`에 있고, `generate.py`가 이 파일도 다시 만듭니다.

## 저장·회로·내보내기

- 여섯 치수와 VBG는 저장 소자·회로의 소자별 snapshot·JSON에서 유지됩니다. 예전 파일은 기준 치수·VBG=0으로 복원합니다.
- 서로 다른 치수/도핑의 소자를 회로에 함께 배치할 수 있습니다. 각 소자는 자체 전계표를 사용하며 전역 도핑 상수를 바꾸지 않습니다.
- VBG는 현재 고정 속성입니다. 독립적인 시간 가변 백게이트 회로 단자가 아닙니다.
- Geometry/VBG 변경은 **결정론 VSCM·CSVM**에 적용합니다. 기준에서만 보정한 확률 잡음 모델은 변경 조건에서 거부합니다.
- 오프라인 데모는 변경 치수의 결과를 만들어 내거나 기준 결과로 대체하지 않습니다. 실제 계산 서버가 필요합니다.
- LTspice·Verilog-A는 선택한 **고정 치수·VG·VBG·광조건**의 준정적 결과를 내보냅니다. 치수를 바꿀 때는 다시 계산하고 내보내야 합니다. 메타데이터가 다른 이전 결과는 거부합니다.
- Sentaurus는 여전히 미지원입니다. 이 compact geometry 확장만으로 메시·도핑 프로파일·접촉·경계조건을 갖춘 TCAD deck이 만들어지지 않습니다.
