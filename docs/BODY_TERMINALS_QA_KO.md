# VBG · 5단자 · CSVM 업데이트 확인

2026-09-25 · 실제 Python solver와 배포용 웹 화면 기준

## 적용한 내용

- VBG는 Si·BOX 직렬 용량과 전면 용량의 divider를 통해 BJT source injection의 유효 바디 바이어스에 반영합니다. 버전은 `fdsoi-bjt-body-bias-v2`입니다.
- 이 결합은 명시적인 **미보정 근사**입니다. 별도 VBG sweep으로 파라미터를 추출하거나 2D Poisson·독립 back-channel·collector 전계 보정을 검증한 것은 아닙니다. 수식·단위·범위는 `GEOMETRY_MODEL_KO.md`에 있습니다.
- 회로에서 G와 BG는 실제 연결된 전압원의 시간 파형을 매 Newton 반복에 반영합니다.
- B는 이상적인 hole 접점이며 `V(B)−V(S)=u`입니다. 외부 RC 전류는 `dQ/dt=F+Ib`에 들어갑니다. 내부 정전기 전위 `ψB`와 접점 전압 u를 혼동하지 않습니다.
- `X1.vb`는 소스 기준 정전기 전위, `X1.vbody`는 소스 기준 접점 전압입니다. 단자 전류는 `I(X1.d/g/s/bg/b)`로 제공합니다.
- BG/B 외부 연결 결과는 `validated=false`로 표시합니다. 기준 부유 바디의 fold를 Body RC가 연결된 회로의 문턱으로 표시하지 않습니다. 이 메타데이터와 화면 분기를 추가로 검사했습니다.
- 연결된 BG·B는 현재 **결정론적 BE**에서 지원합니다. 확률적 모델과 TRAP 확장을 조용히 흉내 내지 않고 명시적으로 거부합니다. 기존 3단자 회로는 보존합니다.

## 첫 피크 오버슈트 재현

조건: 기준 Device 1, VG=−2 V, VBG=0, Iin=1 nA, Cdrain=1 fF, 40 μs, BE, 자동 초기화. 소자 UI가 생성한 실제 요청으로 계산했습니다.

| 값 | 실제 결과 |
|---|---:|
| 파형에 보존된 첫 피크 | 5.493325 V |
| 초기 구간 이후 12주기 Vtop 평균 | 3.695479 V |
| 같은 구간 Vbottom 평균 | 1.811206 V |
| 평균 주기 | 2.433415 μs |
| 주파수 | 410.945 kHz |
| 전류 문턱 래치 이벤트 수 | 1 |

기존 구현은 이벤트가 하나라도 있으면 전압 파형 검출을 건너뛰었습니다. 수정 후에는 이벤트가 놓친 완전한 전압 주기도 검출합니다. 이 경우 `source=waveform`입니다. 원래 파형은 그대로 유지하며, 계산한 극값은 무한 시간의 정상상태가 아니라 명시한 관측 구간의 반복 주기 평균입니다. 드문 극값의 영향을 줄이는 percentile은 검출 prominence에만 적용하고, 표시 파형이나 주기 극값에는 적용하지 않습니다.

기본 1 pF·15 ms 조건에서도 Vtop 3.742 V, Vbottom 2.586 V, 약 860 Hz를 유지합니다. VB(t)는 실제 solver의 정전기 전위를 별도 세로 영역에 같은 시간축으로 표시합니다. 밝은/어두운 테마와 390px 화면을 시각적으로 확인했습니다.

## Body RC와 변조

실제 회로 UI에서 G에 −2→−1.95 V 펄스, BG에 ±0.1 V·50 kHz 사인파를 연결했습니다. B는 20 GΩ과 10 fF에 연결하고 40 μs까지 계산했습니다. 사용자가 최종 B→C 배선을 직접 그리는 경로도 검사했습니다.

- 접점 전압 범위: 약 −0.1041–1.1955 mV.
- 내부 정전기 전위 범위: 약 −8.3610–9.0460 mV.
- Body 전류 범위: 약 −11.925–11.931 pA.
- 단자 전류·외부 body-node KCL·저장 전하의 시간 차분을 점검했습니다.
- 별도 1 GΩ/1 pF 접점 충전 검사에서는 시간상수가 외부 RC에 맞게 변하고 내부 상태 u도 함께 변합니다. 소스 공통 전압을 0.4 V 올려도 상대 동역학은 유지됩니다.

## 기록과 한계

`web/review/body-terminals/`에 실제 JSON 응답과 화면이 있습니다. 재현 테스트는 `web/e2e/body-potential-live.spec.ts`, `web/e2e/five-terminal-live.spec.ts`, `server/tests/test_circuit_five_terminal.py`입니다.

원본 `engine/`는 보존했고 서버의 모델 확장과 회로 solver를 수정했습니다. 이번 검사는 수치·연결·화면 동작의 근거이며 새 VBG/Body-contact 소자의 실험적 정확도 검증은 아닙니다. 새로운 온도·접촉 저항·임의 누설 현상은 추가하지 않았습니다. Windows 네이티브 설치나 연구실 서버 실배포를 이번 검사에 포함하지 않았습니다.
