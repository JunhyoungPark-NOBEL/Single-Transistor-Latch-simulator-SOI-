# 성능 벤치마크와 실행 전 예상 시간

성능 탭은 **Detailed / Simple 모델의 실제 계산 시간**을 비교하고, 실행 버튼 근처에는 현재 설정의 예상 시간을 작게 표시한다. 로컬 앱에서는 사용자 PC의 Python 계산 환경, 연구실 서버에 연결했을 때는 해당 서버의 계산 환경을 기준으로 한다.

## 사용 방법

1. **성능** 탭에서 모델과 시뮬레이션 종류별 기준 시간을 확인한다. 각 행의 조건을 펼치면 계산 길이·치수·반복 횟수 등 비교 조건을 볼 수 있다.
2. **이 환경 측정**을 실행하면 연결된 계산 서버에서 짧은 실제 모델 계산을 수행한다. 첫 실행에는 수치 커널 준비 때문에 시간이 더 걸릴 수 있다.
3. 소자·회로 탭으로 돌아가면 실행 버튼 근처의 예상 시간에 측정 결과가 반영된다. 이후 성공한 실제 실행의 시간도 보정 자료로 사용한다.

환경을 아직 측정하지 않았거나 해당 계산 종류의 보정 자료가 없으면 기준 환경의 추정값으로 구분한다. 브라우저 CPU 정보나 코어 수만으로 Python 계산 속도를 단정하지 않는다. 다른 서버에 연결하면 그 서버의 측정 자료를 사용한다.

환경 측정은 Detailed / Simple 각각의 ID–VD와 CSVM, 총 4개 조건을 실행한다. 측정한 모델·해석 종류에만 보정을 적용하며, 게이트 스윕·확률적 해석 등은 실제 실행 기록이 쌓이기 전까지 기준 환경의 추정값을 사용한다. **이 환경 측정 기록**을 펼치면 현재 호스트에서 얻은 시간을 볼 수 있다. 아래의 모델 비교표는 계속 기준 환경의 실측값을 보여준다.

## 시간표의 의미

- **반복 실행 시간:** 같은 조건을 여러 번 계산한 중앙값이다. 측정 횟수와 범위를 함께 보존한다. 최종 결과 캐시에서 응답한 시간은 계산 속도에 포함하지 않는다.
- **첫 호출:** 모듈·수치 커널·프로파일 준비가 섞일 수 있다. 별도로 기록하며, 빈 컴파일 캐시를 직접 확인하지 않은 결과를 새 JIT 컴파일 시간으로 부르지 않는다.
- **미지원:** Simple의 확률적 해석처럼 현재 계산기가 제공하지 않는 조합이다. 0초나 무한한 속도 향상으로 표시하지 않는다.
- **기본 소자:** MOSFET·diode·BJT만 있는 회로는 STL 모델 선택과 무관하므로 공통 조건으로 표시한다.

벤치마크는 소프트웨어의 실행시간 비교이다. Simple은 Detailed와 근사·기본 파라미터·파형이 다르므로, 빠른 시간이 동일한 물리 정확도를 뜻하지 않는다. 두 모델에는 동일한 외부 입력과 수치 허용오차를 적용하고 실제 사용한 요청을 함께 보존한다.

## 예상 시간이 만들어지는 방법

현재 실행 요청에서 모델, 계산 종류, 격자·게이트 점수, 과도 해석 길이·시간 간격, 회로 크기, 구동 조건, 확률적 반복 횟수 등을 읽는다. 같은 계산 종류의 기준 측정과 해당 계산 환경의 기록을 이용해 시간을 환산한다. 실행 버튼이 여러 계산을 함께 요청하면 병렬 실행과 앞 계산에 의존하는 후속 계산을 구분한다.

표시 범위는 실행 부담을 판단하기 위한 **추정 범위이며 통계적 신뢰구간이 아니다.** 강한 발진, 더 엄격한 허용오차, 새로운 Geometry·바이어스, 큰 혼합 회로처럼 기준 조건에서 멀어지면 오차가 커질 수 있다. 실제 적분 스텝 수나 수렴 실패를 실행 전에 정확하게 알 수는 없다.

다음 시간은 서로 섞지 않는다.

| 항목 | 처리 |
|---|---|
| 모델 계산 | 기준 표와 실제 계산 기록으로 추정 |
| 서버 대기 | 실행 중인 작업·작업자 상태를 별도로 고려 |
| 최초 준비 | 아직 해당 커널을 실행하지 않았다면 추가 준비 가능성을 표시 |
| 결과 캐시 | 계산 재실행과 구분하여 표시 |
| 네트워크·브라우저 렌더링 | 계산 벤치마크에 포함하지 않음 |

실패·취소·중도 종료된 계산, 결과 캐시 응답, 여러 사용자가 함께 받은 동일 계산의 중복 시간은 빠른 정상 실행으로 학습하지 않는다. 측정 자료는 계산 서버와 엔진 버전에 따라 구분한다.

## 재현 자료

- `scripts/benchmark_performance.py`: 모델·종류별 측정 스크립트

- `server/data/performance_catalog.json`: 화면과 예측이 공유하는 기준 시간표
- `docs/benchmarks/performance/`: 실제 요청·측정 원자료
- `docs/PERFORMANCE_QA_KO.md`: 이번 실행판의 확인 결과
