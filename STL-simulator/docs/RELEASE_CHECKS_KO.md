# STL simulator — 확인 범위

2026-09-26

## 성능 탭·실행 전 예상 시간

Detailed / Simple의 모델·해석별 성능 표와 실제 계산 환경의 보정을 추가했습니다. 43개 항목 중 34개를 실측하고 9개 미지원 조합을 구분했습니다. 실측에는 예측 기준에서 제외한 확인용 조건 4개가 포함됩니다. 소자·회로의 실행 버튼에 작은 예상 시간 범위를 표시하며, 로컬 PC 또는 연결된 서버의 측정·정상 완료 기록을 사용합니다. 최초 준비·대기·결과 캐시는 구분합니다.

물리식은 변경하지 않았습니다. 측정 조건·예측 오차·소프트웨어 확인 범위는 [PERFORMANCE_QA_KO.md](PERFORMANCE_QA_KO.md), 사용 방법은 [PERFORMANCE_KO.md](../PERFORMANCE_KO.md)에 있습니다.

## Simple Model 추가

기하 의존 확산 β와 1차 바디 전하 감쇠를 사용하는 Simple Model, HRS 보정, 결정론적 CSVM·5단자 회로 연결을 추가했습니다. 같은 입력의 warm 계산에서 대표 CSVM은 약 10배, 5단자 회로는 약 4배 빨라졌습니다. 첫 컴파일 시간은 제외했으며, 정확도 비교 수치가 아닙니다. [SIMPLE_MODEL_QA_KO.md](SIMPLE_MODEL_QA_KO.md)에 조건과 검사 범위를 기록했습니다.

## VBG·5단자·CSVM 후속 확인

VBG의 BJT 바디 바이어스 근사, G/BG 시간 변조, 외부 Body RC가 연결되는 5단자 회로, 내부 바디 전위 플롯, 첫 피크 오버슈트 이후의 주기 검출을 추가했습니다. 원본 engine은 보존하고 서버의 확장 모델과 MNA를 수정했습니다. 전체 프런트엔드 546개, 새 5단자/기존 Geometry 회로 19개, 기존 회로/기본 소자 73개 검사를 통과했습니다. 실제 API 연결 브라우저 검사도 CSVM 2개·5단자 회로 1개 통과했습니다.

VBG 결합은 미보정 compact-model 가정이며, 연결된 BG/B 단자는 현재 결정론적 BE에서 지원합니다. 실제 오버슈트 수치·RC 조건·검사 범위는 [BODY_TERMINALS_QA_KO.md](BODY_TERMINALS_QA_KO.md)에 있습니다. 아래 내용은 앞선 UI 및 초기 실행판의 기록입니다.

## 화면 개편 후속 확인

앱 이름을 STL simulator로 통일하고 색상·글씨 크기·수식 서체·모드 선택을 개선했습니다. FDSOI 단면도와 Geometry 입력을 연결했으며 PDSOI·Bulk 실행을 차단했습니다. 이 변경에서는 수치식과 원본 엔진을 수정하지 않았습니다.

| 확인 항목 | 결과 |
|---|---|
| 프런트엔드 단위 검사 | 36개 파일, 536개 통과 |
| TypeScript 및 배포용 화면 빌드 | 통과 |
| 실제 API에 연결한 Chromium 화면 검사 | 3개 통과, 수치 응답 모의 처리 없음 |
| 수식 서체·치수 클릭/키보드·새로고침 후 보존 | 통과 |
| 390px·320px 모바일 및 밝은/어두운 테마 | 가로 넘침 없음 |
| 표시 크기 | 주요 입력·탭 14px, 그래프 눈금 13px 확인 |
| 제품명 API 응답 검사 | 1개 통과 |

실제 VSCM·CSVM 결과를 사용한 화면·조건은 [UI_REFRESH_QA.md](UI_REFRESH_QA.md)와 `web/review/stl-ui/`에 있습니다. 일부 결과는 실제 작업 프로세스가 계산한 서버 캐시에서 읽었습니다. 이 검사는 화면 동작을 확인하며 새로운 물리 정확도를 입증하지 않습니다. 회로 화면 캡처는 배치·색상 확인용이고 이번에 회로 수치 회귀를 재실행한 것은 아닙니다.

Windows 자동 설치 구성은 유지했습니다. 아래 초기 실행판의 물리·배포 검사와 이번 화면 검사는 별도 범위입니다.

## 앞선 독립 실행판의 확인 기록

Windows 자동 설치 후속 수정: 공식 CPython 3.13.15 x64 설치 파일을 포함하고, 사용 가능한 Python이 없는 경우 현재 사용자용 자동 설치를 추가했습니다. 파일 SHA-256을 공식 배포값과 대조했고 Windows CPython 3.13용 NumPy·SciPy·Numba·llvmlite 바이너리 배포가 실제 다운로드되는 것을 확인했습니다. 기존 Python 실행기의 8개 검사는 다시 통과했습니다. PowerShell 동작 검사 21개가 통과했습니다. Python 탐색·자동 설치 분기·해시/서명 거부·중복 설치 방지·한글 출력·오류 로그·인자/종료 코드 전달을 검사했습니다. 설치·서명 검사 경로는 모의 실행이며, 실제 자식 Python 출력은 실행해서 확인했습니다. Windows 네이티브 설치·실구동은 아직 검증하지 않았으며, 기존 브라우저·수치 검사나 Linux의 PowerShell 검사를 Windows 실기 검증으로 간주하지 않습니다.

이 문서는 이번 독립 실행판의 확인 기록입니다. 테스트 통과는 소프트웨어 동작의 근거이며, 새로운 치수·도핑 조건에 대한 측정 정확도를 뜻하지 않습니다.

| 확인 항목 | 결과 |
|---|---|
| 프런트엔드 단위 검사 | 35개 파일, 524개 통과 |
| TypeScript 및 배포용 화면 빌드 | 통과 |
| Geometry·결정론·회로 수치 회귀 검사 | 170개 통과, 7개 제외 |
| API·인증·실제 HTTP 계산 검사 | 관련 실행 합계 185개 통과 |
| 로컬 실행기 검사 | 8개 통과, 실제 준비 상태·중복 실행 거부·종료 정리 확인 |
| 실제 배포용 화면의 Chromium 검사 | 9개 통과 |
| 원본 엔진 보존 | 입력 소스 ZIP의 66개 엔진 파일과 바이트 단위 일치 |

각 행은 별도의 검사 범위입니다. 일부 검사는 다른 범위에도 포함되므로 하나의 총계로 더하지 않습니다. 수치 회귀 실행에서는 긴 실행 항목과 API 항목 일부를 제외했고, API는 별도 실행으로 확인했습니다.

## 실제로 계산한 화면

- 기준 치수 및 L = 400 nm의 ID–VD. 로그/선형 전환과 확대 후 전환.
- Iin = 1 nA, Cdrain = 1 pF의 CSVM. Vtop·Vbottom·주파수 표시.
- 사용자가 직접 배치하고 배선한 2 V 전압원·1 kΩ 저항: 2 mA.
- STL을 포함한 회로의 과도 응답.
- 별도 비밀번호 보호 API에 다른 출처의 화면으로 접속한 실제 계산. 서버 캐시를 비운 상태에서 확인.

상세 조건과 수치는 [STUDIO_QA.md](STUDIO_QA.md)에 있습니다. `web/review/studio/`의 화면 및 JSON은 실제 계산 기록입니다. 연결 실패·이전 응답 폐기만을 검사하는 일부 테스트는 경로를 가로채며, 이를 물리 계산의 근거로 세지 않았습니다.

## 모델 범위

- 원본 수치 엔진은 유지했습니다. 기존 식과 Geometry 확장의 물리 관계·단위·가정을 검토했습니다.
- Tsi의 유효 수명 스케일링은 표면 지배 가정입니다. 표면 재결합 기여율을 측정에서 새로 추출한 것은 아닙니다.
- Tbox = 140 nm는 명시적 기준 가정이며, 백게이트 결합과 기준점에 맞춘 증분 전하식의 한계를 문서에 적었습니다.
- 임의의 양자효과 문턱, 강제 VLU/VLD 보정, BJT 장벽 이동은 추가하지 않았습니다.
- 기존 엔진에서 잘못 실행될 수 있는 활성 local-avalanche 모드 2는 오류로 차단합니다. 일반 MOS 기본 소자는 300 K에서 SS ≥ 60 mV/dec 범위로 제한합니다.
- 기준 치수와 다른 조건은 **확장 · 미보정**으로 표시합니다. 다중 치수 측정 및 TCAD 교차 검증은 수행하지 않았습니다.

자세한 근거는 [PHYSICS_AUDIT_KO.md](PHYSICS_AUDIT_KO.md)와 [GEOMETRY_MODEL_KO.md](../GEOMETRY_MODEL_KO.md)를 참고합니다.

## 배포·내보내기 한계

- Linux의 실제 Python 실행기와 브라우저 연결은 확인했습니다. Windows/macOS의 기본 실행 스크립트는 포함했지만 해당 운영체제에서 실구동하지 않았습니다.
- Docker·Compose·nginx·systemd 설정을 포함했습니다. 이 실행 환경에는 Docker가 없어 컨테이너 빌드는 실행하지 않았습니다.
- 연구실의 실제 서버 주소·관리 권한이 제공되지 않아 해당 서버에 설치하지 않았습니다. 설치 절차는 [STUDIO_START_KO.md](../STUDIO_START_KO.md)에 있습니다.
- LTspice·Verilog-A 내보내기는 고정 Geometry·바이어스 조건의 준정적 모델입니다. 상용 시뮬레이터 바이너리로 실행 검증하지 않았습니다.
- Sentaurus TCAD 입력을 생성할 충분한 공정·구조·물리 보정 정보가 없어 해당 내보내기는 사용 불가로 표시합니다.
