# Simple Model 실제 회로 실행시간 검토

실제 결정론적 BE 회로 계산을 호출했다. 결과 캐시, API 대기, 네트워크, 화면 렌더링은 제외했다. 같은 외부 전압/전류/커패시터와 같은 허용오차를 사용했다. V_G=-3 V, CSVM I_IN=1 nA. 워밍업 후 모델 순서를 번갈아 실행한 3회 중앙값이며, 공유 실행 환경의 대략적인 시간이다. 첫 JIT 컴파일 시간은 아래 비교에서 제외했다.

| 경우 | Detailed | Simple | 속도비 |
|---|---:|---:|---:|
| CSVM 1 pF, 15 ms | 1.0695 s | 0.1029 s | 10.39× |
| CSVM 1 fF, 40 µs | 0.3076 s | 0.1300 s | 2.37× |
| 독립 발진기 4개, 1 pF, 15 ms | 3.8767 s | 0.3253 s | 11.92× |
| 전압 구동 + Body RC, 40 µs | 0.0137 s | 0.0098 s | 1.40× |
| 5단자 CSVM, BG 변조 + Body RC, 40 µs | 0.9005 s | 0.2291 s | 3.93× |

두 모델의 파형과 임계점은 같지 않다. 미보정 Simple 기본값이므로 정확도 비교 자료로 해석할 수 없다. 1 pF 조건에서 Detailed/Simple의 주파수는 약 2.386/1.769 kHz, 스텝 수는 18,667/16,847이었다. 1 fF에서는 Simple의 스텝 수가 더 많아 2.37배 정도의 단축에 그쳤다. 실제 속도비는 바이어스, 소자 수, 수렴 난이도에 따라 달라진다.

5단자 사례의 자동 초기화는 외부 Body 부하가 있는 소자를 부유 바디 fold로 판정하지 않도록 수정한 뒤 다시 측정했다. Body가 연결된 경우 부유 바디 준정적 주파수/발진 여부를 예측값으로 표시하지 않는다. 실제 적분 결과를 사용한다.

검증: Simple 회로 테스트 12개 + 기존 5단자 9개 + Geometry 회로 10개 = 31개 통과. 실제 Body RC의 시간 응답, 바디 전하 보존, 혼합 Simple/Detailed 회로, G/BG 변조 전류, 저장소 전위 w=u+I_D R_LRS, 결정론적 BE 전용 경계를 확인했다.

재현 기록은 `docs/benchmarks/simple/`의 입력·출력 JSON 및 `measurements.json`에 있다. 저장된 마지막 비교 조건을 그대로 확인할 수 있다. 재실행은 프로젝트 루트에서 다음 명령을 사용한다.

```bash
python scripts/benchmark_simple.py --project . --out /tmp/stl-simple-benchmark
```

Windows에서는 `--out`에 `C:/temp/stl-simple-benchmark`처럼 실제 출력 폴더를 지정한다.

## 모델과 소프트웨어 확인

- Simple 물리·수치 관계 13개: β의 바이어스 불변성 및 L/Nbody 의존성, W/Tsi 면적 상쇄, 1차 감쇠, 전하 보존, BTBT 적분, Miller 범위, 두 fold와 L 경향.
- HRS 보정 14개: 한 항목·두 항목의 알려진 정답 복원, 다른 Geometry에서 기준 파라미터 복원, 부적절한 입력·동시 보정 식별 실패·미지원 모드 거부. 합성 데이터 복원은 측정 정확도 검증이 아니다.
- 새 Simple 및 기존 5단자·Geometry 회로 31개 통과. 실제 RC 시간 응답과 혼합 모델 회로를 포함한다.
- 기존 결정론·기하·회로·API 범위 131개 중 130개가 첫 실행에서 통과했다. 나머지는 새 `simple_calibrate` 종류를 기대하지 않던 API 목록 검사였으며, 기대 목록 갱신 후 메타데이터·모델 캐시 무효화 검사 2개를 재확인했다. 각 범위는 중복 항목이 있으므로 합산하지 않는다.
- 원본 `engine/` 66개 파일은 제공된 소스 ZIP과 바이트 단위로 동일하다. 새 모델은 `server/`에 분리했다.
- Linux에서 로컬 실행기의 의존성·완성 UI·API import 확인을 통과했다. Windows 설치 및 연구실 실서버 배포는 이 실행 환경에서 다시 수행하지 않았다.

최초 JIT 컴파일은 속도표에 포함하지 않았다. Simple도 공용 회로 커널의 첫 컴파일을 기다릴 수 있다. 업데이트할 때 이전 계산 결과가 사용되지 않도록 결과 캐시에 Simple 수식·기본값의 소스 지문을 포함했고, 새 평가기를 포함하도록 MNA 컴파일 캐시도 무효화했다.

Simple 기본값은 HRS 측정에 새로 보정한 값이 아니다. 물리식·기하 가정 및 부호 있는 전하 좌표의 적용 범위는 [SIMPLE_MODEL_KO.md](../SIMPLE_MODEL_KO.md)를 참고한다.

## 실제 화면 확인

배포용 화면 빌드와 프런트엔드 38개 파일·560개 검사를 통과했다. 실제 API에 연결한 Playwright 시나리오 1개도 통과했다. Simple 최초 선택 시 VG=−3 V, 확률적 모드 제한, ID–VD, HRS 보정·적용·저장, 상용 내보내기 제한, CSVM 드레인·바디 플롯, 모델 변경 후 이전 결과 구분, 저장 소자 다시 불러오기를 확인했다. 390px 모바일에서 가로 넘침이나 페이지 오류가 없었다.

ID–VD·HRS 보정·CSVM 요청은 모두 결과 캐시를 사용하지 않은 실제 계산이었다. 합성 HRS 보정의 log10 전류 RMSE는 1.22×10⁻¹⁵였으며 β=2.3을 고정했다. 화면의 CSVM은 Vtop=2.3163 V, Vbottom=1.7538 V, f=1.7690 kHz, 초기 구간을 제외한 20주기를 표시했다. 이것은 미보정 Simple 시작값의 계산 결과이며 측정값이 아니다.

스크린샷과 원본 응답 기록은 `web/review/simple-model/`, 재현 시나리오는 `web/e2e/simple-model-live.spec.ts`에 있다.
