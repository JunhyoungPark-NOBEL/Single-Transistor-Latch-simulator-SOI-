Simple Model

바디 전하의 1차 감쇠로 CSVM과 회로를 빠르게 계산하는 모델입니다.

결정론적 · BEGeometry 반영HRS 보정

분포 SRH 수송 풀이를 생략하고, 재결합을 Q/τB로 계산합니다. β는 바이어스에 대해 일정하며 소자의 길이와 도핑에 따라 달라집니다.

초기값은 논문을 바탕으로 정한 시작값입니다. Device 1의 측정 보정을 계승하거나 새 모델의 정확도를 독립적으로 검증한 값은 아닙니다.

시작하기

  1. Simple Model을 선택합니다. 기본 시작 게이트 전압은 VG = −3 V입니다.
  2. Geometry와 바이어스를 맞춘 뒤, HRS의 전압·전류로 IS 또는 τB를 보정합니다.
  3. ID–VD를 확인한 다음 CSVM이나 회로에서 동작을 비교합니다. 재결합 근사가 첫 피크와 주파수에도 영향을 줄 수 있습니다.
핵심 수식

접촉 전압 u, 내부 드레인 전압 r, 전하 저장 영역의 전위 w를 구분합니다.

M = [1 − (r/VBR)η]−1 Iseed = IS exp(u/VT) ID = MIseed + IBTBT + Iph VD = r + IDRLRS w = u + IDRLRS Q = CB(w − Vbias) dQ/dt = (M−1)Iseed + IBTBT + Iph 　　　　− Iseed/β − Q/τB + IB,ext

IBTBT는 측방향 BTBT와 GIDL의 합입니다. GIDL 전계에는 내부 전압 r를 사용하는 근사를 적용합니다. 기존 모델의 비선형 SRH 손실·추가 수송 전하·채널 전류를 중복해서 더하지 않습니다.

Q는 바이어스 기준의 부호 있는 전하 좌표입니다. 음수일 때의 Q/τB는 선형 복원 항이며, 음의 미시적 재결합률을 뜻하지 않습니다.

Geometry와 β
β = βref (Lref/L)(Nref/Nbody) IS = IS,ref (W/Wref)(TSi/TSi,ref) 　　　　× (Lref/L)(Nref/Nbody)

에미터 도핑·확산 계수·홀 확산 길이가 고정된 확산 근사입니다. 두 전류의 접합 면적이 같아 β에서 W·TSi가 상쇄됩니다. 베이스 길이는 L로 근사합니다.

입력모델에 연결되는 항
L, W, TSi확산 전류, LRS 저항, 저장 정전용량
Tox / EOT전면 결합 정전용량, GIDL 전계
TboxSi/BOX 직렬 정전용량을 통한 백게이트 결합
Nbody확산 전류와 β, 측방향 BTBT 전계

τB = τref/[(1−fsurf) + fsurfTSi,ref/TSi]. 표면 기여율 fsurf의 기본값 1은 가정이며, 측정으로 분리 추출한 값이 아닙니다.

HRS 보정은 어디까지 가능한가요?

한 점에서는 IS 또는 τB 중 하나를 보정합니다. 두 값을 함께 조정하려면 전압이 구분되는 HRS 데이터가 최소 3점 필요하며, 그 경우에도 두 값의 구분이 가능한지 확인해야 합니다.

정적 HRS는 주로 τB/CB를 결정하므로 보정 중 CB는 고정합니다. IS와 수명이 서로 비슷한 효과를 내면 여러 조합이 동일한 전류를 설명할 수 있습니다.

보정 후 실제 낮은 전류 HRS 가지를 다시 계산해 로그 전류 오차를 표시합니다. HRS 밖의 점, 구분할 수 없는 데이터, 지나치게 큰 잔차는 적용하지 않습니다.

입력한 HRS에 잘 맞는다는 것은 fold, CSVM 주파수, 다른 Geometry의 정확도를 보증하지 않습니다. 보정에 쓰지 않은 데이터로 비교하세요.

Body RC · 게이트 변조

D·S·G·BG·B의 5단자와 G/BG의 시간 변화 입력을 지원합니다. B에 RC를 연결하면 바디 전하 방정식에 외부 전류가 함께 들어갑니다.

B 접점 전압은 u, 바디 플롯은 저장 영역 전위 w입니다. 회로에서 X1.vbody는 전자, X1.vb는 후자입니다. 모두 S 기준 전압입니다.

B 접점의 위치와 IDRLRS의 전압 관계는 논문의 모델을 회로용으로 확장한 집중소자 근사입니다. 외부 Body RC의 정확도가 별도로 검증된 것은 아닙니다.

결정론적 BE 해석만 지원합니다. Simple Model의 확률적 해석과 LTspice·Verilog-A·Sentaurus 내보내기는 현재 제공하지 않습니다.

Miller 식의 범위는 0 ≤ r < VBR입니다. 시작·작은 링잉을 위해 −50 mV까지 M = 1, BTBT = 0으로 연장하지만, 정확한 영바이어스 평형이나 역방향 트랜지스터 동작 모델은 아닙니다.
